📐 Mathematical Reference & Guide

How to Write Equations

y = 2x + 1 Linear slope-intercept form
x^2 + y^2 = 10 Circular loop with radius √10
x^2 + y^2 = 16 { y < 0 } Semicircular bowl (halfpipe)
y = -0.5(x - 2)^2 + 4 Parabola with vertex at (2, 4)
y = 2 * sin(x) Trigonometric wave
x = 3 Vertical wall / barrier
y = 4 / (x + 2) Rational hyperbolic curve
y = abs(x) - 3 Absolute value V-ramp

Domain Restrictions

Truncate slides so marbles can fall or drop into target zones:

y = -0.5x + 3 { x < 2 } Line ends at x = 2
y = x^2 - 4 { -3 < x < 3 } Curve only drawn between -3 and 3

Sliders & Parameters

Use variables like a, b, m in your equations (e.g., y = m*x + b). Sliders will automatically appear for instant dynamic tuning!
